# SAI Governance Challenge

English-only React/Vite game for GitHub Pages.

The game is a simplified research-based simulation of stratospheric aerosol injection (SAI) governance from 2030 to 2130. Players choose a temperature target, injection season, injection location, particle material, and optional support actions. The outcome depends on temperature, Arctic ice, food security, rainfall/monsoon stability, public trust, scientific knowledge, aerosol burden, and infrastructure stability.

The game includes a knowledge/insight mechanic: detailed cause-effect explanations are locked at the beginning and become visible only when scientific knowledge increases through laboratory testing and monitoring.
